# مصفوفة تصميم حالات اختبار Laravel API

استخدم المصفوفة التالية لاختيار الحالات المناسبة لكل endpoint، ولا تنشئ حالات لا تنطبق على العملية:

| الفئة | الحالة | النتيجة المتوقعة |
|---|---|---|
| النجاح | طلب صحيح | status وJSON مطابقان للعقد |
| التحقق | حقل مفقود/صيغة خاطئة | 422 ورسائل حقول متوقعة |
| المصادقة | دون token/session | 401 أو السلوك الموثق |
| الصلاحية | مستخدم مصادق بلا إذن | 403 |
| الملكية | محاولة قراءة/تعديل سجل مستخدم آخر | رفض دون تسريب البيانات |
| المورد | سجل غير موجود | 404 |
| التكرار | نفس طلب الإنشاء مرتين | سلوك واضح يمنع التكرار الضار عند الحاجة |
| الحدود | قيم دنيا/عليا وطول/عدد كبير | قبول أو رفض موثق |
| القائمة | لا توجد نتائج أو نتائج كثيرة | بنية pagination ثابتة |
| الاعتمادية | خدمة خارجية متوقفة/مهلة | خطأ آمن ومفهوم دون كشف تفاصيل حساسة |

لا تعتمد على status code وحده؛ افحص body والآثار على قاعدة البيانات أيضًا.
